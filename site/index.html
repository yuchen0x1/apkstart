CORE FEATURES

像用原生软件一样用安卓应用

从安装到启动、从窗口到搜索、从数据到备份，ApkStart 把安卓应用完整地接进 Windows 的使用习惯里。

🖱️

双击 .apk 即安装

注册 .apk 文件关联后，在资源管理器里双击 APK，自动解析 → 安装 → 生成桌面图标，全程无需打开任何模拟器界面。

🧩

每个应用一个桌面图标

图标从 APK 内部离线提取并转为多尺寸 ICO，双击桌面图标直接启动该应用，与打开原生 Windows 软件的体验一致。

🪟

应用就是一个窗口

窗口带真实应用图标、按竖屏比例摆好位置；全屏铺满屏幕高度并居中，窗口模式可自由拖动缩放且按应用记忆尺寸。

🔍

能被 Windows 搜到

安装后创建桌面 + 开始菜单快捷方式，按应用名在开始菜单搜索即可直达，任务栏按应用分组。

📁

数据互通

本机共享目录与安卓 /sdcard 持续双向同步，按内容哈希三方合并，两侧都改会保留两份并生成冲突副本，不会静默覆盖你的文件。

🩺

装之前先告诉你行不行

兼容性检查覆盖系统版本、原生库架构、Google Play 依赖、硬件权限、拆分 APK 分片，结论分四档并给出理由；拿不准的标「未知」。

💾

导出与备份

右键任意应用可导出 APK，或生成 app.apk + meta.json 备份目录，之后一键装回。拿不到的数据如实写明原因，不冒充「备份成功」。

🪶

极致轻量

壳层零第三方依赖（ZIP / PNG / ICO / AXML 解析都是手写的），运行时按需拉起、空闲自动回收，也可完全复用本机已有安卓运行时。

HOW IT WORKS

从双击到启动，四步直达

没有模拟器控制台，没有多余界面——用户看到的只有应用本身。

双击桌面图标

每个已安装应用都有真实图标快捷方式（.lnk），双击即触发 ApkStart.exe --launch 包名。

按需拉起运行时

运行时未启动则自动拉起 Android Emulator（API 34）；空闲自动回收，也可复用本机已有运行时。

解析真实入口启动

按系统解析出的 LAUNCHER 入口启动（而非 APK 里的主 Activity），并做 18 秒存活观察与自动恢复。

窗口即应用

模拟器窗口自动改标题、换真实应用图标、按竖屏比例摆放——全屏居中或自由窗口，F11 随时切换。

运行时自持管理 · 位于 %APPDATA%\apkstart\runtime · 数据与快照可迁移到其它盘
REQUIREMENTS

配置要求

没有硬件加速也能跑（纯软件模拟），但推荐开启虚拟化以获得流畅体验。

项最低推荐
系统Windows 10 x64（1903+）Windows 11
CPU4 逻辑核，支持虚拟化（VT-x / AMD-V，未开启时走软件模拟）8 核及以上
内存8 GB16 GB 及以上
磁盘约 8 GB 可用空间（镜像 + 数据分区 + 快照）20 GB 及以上（装大型游戏更宽裕）
显卡无硬性要求（无加速时自动软件渲染）支持 OpenGL ES / Vulkan 的独显或核显
网络仅首次部署需要联网下载运行时（完整版离线可用）—
Windows 7 / 8 不能运行——依赖 Electron 23+ 与新版 WHPX / AEHD 加速组件。建议在 BIOS 开启虚拟化并勾选「虚拟机平台」Windows 功能，或使用内置 AEHD 驱动。
C 盘空间紧张？在「设置 → 系统集成」里把运行时数据目录与安卓数据目录改到其它盘，应用与存档不会丢；已生成的 AVD 目录可整体剪切后切换设置。
